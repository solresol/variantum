# Variantum agent instructions

## Private administration

Before handling collaborator correspondence, co-author approvals, HREC,
Macquarie Pure, grant reporting or other project administration, read
`admin/AGENTS.md`.

The `admin/` directory is intentionally excluded from Git. It is a local bridge
to the private sibling repository at `../variantum-admin`; it is not a source of
public project content. If the bridge is absent in a fresh checkout, use
`../variantum-admin` directly and recreate the local bridge if appropriate.

Keep publishable research, software, paper sources and public-safe plans in this
repository. Keep email, contact details, ethics administration, grant
administration and other private records in `../variantum-admin`. Do not copy
private administrative material into tracked Variantum files.
